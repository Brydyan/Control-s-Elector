## KEY LESSONS

1. ENTITY-SERVICE COORDINATION
   New service layer = identify ALL FK dependencies upfront
   Order matters: roles → usuarios → jrvs → cargos → actas

2. NATIVE SQL vs ORM
   Native INSERT doesn't trigger JPA @Defaults
   Always set all NOT NULL columns explicitly

3. RESPECT SCHEMA CONSTRAINTS
   Unique constraints enforce business rules (not bugs)
   Test data must honor: FK, PK, UNIQUE, NOT NULL

4. TEST DATA ISOLATION
   @BeforeEach + fixture = independent, repeatable tests
   No cross-test pollution
