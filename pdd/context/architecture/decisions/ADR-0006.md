# ADR-0006: Full test pyramid (unit + integration + E2E).

- **Estado:** Aceptado
- **Etapa:** testing_strategy
- **Decisión:** C
- **Por Qué (Justificación de Negocio):** El producto es de misión crítica y el fallo de un acta se descubre tarde, en el escrutinio: la red de seguridad no puede depender de QA manual en jornada. La capa de integración con Testcontainers protege el contrato de las transiciones del acta (BORRADOR -> ENVIADA -> EN_DISPUTA -> CORREGIDA -> APROBADA) y la de E2E cubre el camino de campo con conectividad intermitente.
- **Restricción para Agentes de IA (Guardrail):**
  - Cada transición del ciclo de vida del acta necesita cobertura de integración antes de llegar a develop.
  - Los E2E de flujo crítico corren contra la misma API que producción: nada de mocks en la ruta de registro de acta.
