# ADR-0001: Full-stack application (B2B SaaS or B2C user-facing product).

- **Estado:** Aceptado
- **Etapa:** system_nature
- **Decisión:** C
- **Por Qué (Justificación de Negocio):** Es un producto propio, no una librería ni una API headless: la persona usuaria (veedor, coordinador, administrador electoral) entra a una aplicación con su sesión y su rol. La mitad backend existe para sostener esa experiencia de campo, no para integrarse con terceros.
- **Restricción para Agentes de IA (Guardrail):**
  - El frontend Angular y el backend Quarkus se despliegan y versionan juntos: no hay contrato público reutilizable fuera del producto.
  - Capas del backend: resource (REST) -> application (casos de uso) -> domain (reglas) -> persistence (Panache).
