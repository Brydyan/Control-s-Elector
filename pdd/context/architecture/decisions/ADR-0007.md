# ADR-0007: Kubernetes / cloud-native (AWS ECS, GKE, etc.).

- **Estado:** Aceptado
- **Etapa:** infrastructure_deployment
- **Decisión:** D
- **Por Qué (Justificación de Negocio):** El sistema tiene que estar disponible y auditable durante la jornada, con despliegue repetible y reversión inmediata si una versión sale mal: ArgoCD sobre Kubernetes da esa trazabilidad, y separar secretos de configmap permite rotar el JWT secret sin tocar la imagen. Compose se conserva para desarrollo.
- **Restricción para Agentes de IA (Guardrail):**
  - Ningún secreto se versiona: todo va por Secret de Kubernetes y .env.example es la única plantilla compartida.
  - El despliegue de producción es ArgoCD sobre k8s/: un kubectl apply manual rompe la trazabilidad del rollout.
- **Evidencia:**
  - k8s/: kubernetes manifest directory
