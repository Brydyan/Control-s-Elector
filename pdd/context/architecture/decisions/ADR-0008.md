# ADR-0008: Full observability: logs + metrics + traces (OpenTelemetry).

- **Estado:** Aceptado
- **Etapa:** observability
- **Decisión:** D
- **Por Qué (Justificación de Negocio):** En un sistema electoral un fallo silencioso es un fallo electoral: si un acta se queda sin consolidar, el resultado consolidado miente y nadie se entera hasta que ya no se puede corregir. Por eso se decide el nivel completo y no solo logging, y por eso las métricas cubren el pipeline de actas y no solo el Health de Quarkus.
- **Restricción para Agentes de IA (Guardrail):**
  - Ningún log lleva token ni refresh token ni credenciales de la persona observada.
  - Health de proceso no es salud del producto: las métricas cubren el pipeline de actas (enviadas / en disputa / aprobadas) y no solo el liveness del contenedor.
