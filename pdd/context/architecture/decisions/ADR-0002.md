# ADR-0002: Greenfield / new product: initial functional release with defined boundaries.

- **Estado:** Aceptado
- **Etapa:** scope_mvp
- **Decisión:** A
- **Por Qué (Justificación de Negocio):** El ciclo electoral 2027-2031 es el primer período de operación real del producto: el alcance de esta intervención es el release funcional inicial con sus límites definidos. La migración Spring -> Quarkus en curso es un trabajo de runtime y no cambia el contrato de producto, así que no define el horizonte de esta intervención.
- **Restricción para Agentes de IA (Guardrail):**
  - No ampliar el alcance del release inicial sin plantearlo antes como cambio de producto explícito.
  - Todo lo declarado invariante en un ADR requiere una decisión humana explícita para cambiarse.
