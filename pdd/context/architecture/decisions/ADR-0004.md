# ADR-0004: Relational database (PostgreSQL, MySQL, SQLite).

- **Estado:** Aceptado
- **Etapa:** data_architecture
- **Decisión:** A
- **Por Qué (Justificación de Negocio):** El valor del producto es la integridad del acta: la coherencia entre padrón, votos válidos, blancos y nulos exige transacciones ACID y constraints en el esquema, que un almacén de documentos no da. Las fotos son el único payload grande y no se consultan relacionalmente, así que van a object storage.
- **Restricción para Agentes de IA (Guardrail):**
  - Liquibase es el único dueño del esquema: el mapeo ORM es explícito en cada entidad y no depende de conversiones implícitas.
  - Las evidencias se comprimen a .webp en el cliente y se almacenan como objetos en object storage; nunca como BYTEA en PostgreSQL.
